# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to capture and upload a chili leaf image in JPG, JPEG or PNG format.
2. The system shall analyse the uploaded image using an AI-based image classification model.
3. The system shall display the predicted disease category or healthy based on the uploaded image.
4. The system shall display advisory information related to the predicted disease category.
5. The system shall display basic preventive measures and disease management recommendations for the predicted disease category.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display the classification result within 5 seconds after a valid image has been uploaded.
2. The system shall allow users to complete the image upload and disease classification process within 3 steps, excluding the time required to select the image.
3. The system shall successfully process at least 95% of valid test images under the defined testing conditions.
