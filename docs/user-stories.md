# User Stories



1. As a chili farmer, I want to capture or upload an image of a chili leaf so that I can identify the possible disease affecting my chili plant. (FR1)
    Acceptance Criteria:
        -The system shall allow users to capture an image of a chili leaf using their mobile device camera.
         -The system shall allow users to upload an existing chili leaf image from their device.
2. As a chili farmer, I want to view the disease symptoms, preventive measures, and recommended actions based on the detection result so that I can understand how to manage the disease affecting my chili plant. (FR2)
    Acceptance Criteria:
        - The system shall display disease information corresponding to the predicted disease category.
        - The system shall provide symptoms or characteristics associated with the identified disease.
3. As a chili farmer, I want to view my previous disease detection results so that I can refer to earlier diagnoses and monitor the results of my chili leaf checks.
    Acceptance Criteria:
        -The system shall save the previous detection results.
        -The system shall display the disease category predicted for each previous detection.
