# User Stories



1. As a chili farmer, I want to capture or upload an image of a chili leaf so that I can identified my plant health condition.(FR1)
Acceptance criteria:
    -Uploading a JPG, JPEG or PNG image allows the system to accept the image.
    -Uploading a valid image allows teh system to analyse the image.

2. As a chili farmer, I want the system to identify the possible diseases from my uploaded leaf iage so that I can understand the condition.(FR2,FR3)
Acceptance criteria:
    -Analysing an uploaded image displays the predicted disease category.
    -If the leaf is healthy, the system displays the results as healthy.
    
3. As an agricultural student, I want to view advisory information about the detected disease, so that I can learn how to manage and prevent the disease.(FR4,FR5)
Acceptance criteria:
    -Displaying an advisory information related to the predicted disease category.
    -Displays preventive measures related to predicted disease.
